# EZ Stream releases

Installers and updates for **EZ Stream**, a Windows app to watch streams and go live on several platforms at once, without OBS.

- **Download:** the newest installer is under [Releases](../../releases/latest).
- **Updates:** an installed copy checks here and updates by itself. Each update is signed, and the app only installs updates that carry its signature.

This repository has only the release files. The app's source code is not here.
